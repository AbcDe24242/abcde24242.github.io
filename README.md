# 鸣语

**赵子鸣及其友人言行录**

作者：**AbcDe**

一部体例仿《论语》的文言作品集，记录赵子鸣（书中称「鸣」）及其友人的日常言行。每条以「文言原文 · 白话译文 · 或曰评论」三段呈现，寓讽喻于谐趣。

## 体例

- **文言**：仿《论语》之简古，记言为主，兼及行事。
- **译文**：白话译文，便于今人阅读。
- **或曰**：一句评论收束全条，点明题旨，仿《论语》之评语体。
